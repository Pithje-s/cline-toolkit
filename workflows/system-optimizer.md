---
description: Оптимизация системы/игр/софта — выполняется кодом (PowerShell/реестр/конфиги), а не советами; всегда бэкап перед изменением.
---

При вызове активируй навык `system-optimizer`.

- Найди цель: конфиги (`%LOCALAPPDATA%\<Game>\`), службы (`Get-Service`), ключи реестра (читай текущее значение до правки).
- Сделай бэкап ДО изменений: `reg export` для реестра, `Copy-Item` для конфигов, `Checkpoint-Computer` для точки восстановления; сохрани путь отката.
- Примени изменение скриптом: `Stop-Service`+`Set-Service -StartupType Disabled`, `Set/New-ItemProperty`, `(Get-Content) -replace ... | Set-Content`.
- Докажи результат (вывод команды / before-after) и предложи запуск готового скрипта: «Я подготовил скрипт для <цель>. Запускаю?».
- Без советов в стиле «зайди в настройки и нажми»; системные/admin-изменения — только после подтверждения; всегда указывай путь отката.

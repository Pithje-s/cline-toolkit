Консолидация памяти: сжать и почистить Memory Bank, когда контекст переполнен. Запускается вручную.

-globals: [manage_knowledge, sequential-thinking]

## Когда запускать

- Контекст переполнен / раздут устаревшими записями
- Пользователь говорит: консолидируй память, сожми memory bank, почисти контекст
- Перед новой крупной фазой работы, чтобы облегчить окно внимания

## Цель

Уменьшить объём Memory Bank, сохранив только то, что реально нужно для продолжения работы: ключевые архитектурные решения и актуальный контекст. Не раздувать окно внимания.

## Шаги

### 1. Прочитай весь Memory Bank
Прочитай все файлы: product, activeContext, progress, nextTask, decisionsLog и опциональные (productContext, systemPatterns, techContext).

### 2. Найди устаревшее и неактуальное
Помечай для удаления:
- Решённые проблемы (закрытые баги, выполненные подзадачи)
- Старые планы, которые уже не актуальны
- Дублирующиеся записи об одном и том же
- Черновые заметки, потерявшие контекст
- Задачи, которые давно завершены и больше не влияют на решения

Сохраняй:
- Действующие архитектурные решения и их обоснование
- Текущий фокус и ближайшие шаги
- Активные проблемы и ограничения
- Контракты/данные, от которых зависит код

### 3. Сожми оставшееся
- Суммаризируй длинные списки в сжатые пункты (ключевое + ссылка на детали, если нужно)
- Объединяй дубли, оставляй одну каноническую формулировку
- Сохраняй хронологический порядок в логах решений
- Не удаляй информацию молча — заменяй объёмное на сжатое

### 4. Обнови файлы
Перезапиши каждый консолидированный файл (используй update_memory_bank). Покажи, что убрано и что сжато.

### 5. Отчитайся
```
MEMORY CONSOLIDATED
- <file>: <что удалено> / <что сжато>
- Ключевые решения сохранены: <перечень>
- Текущий контекст сохранён: <фокус, следующие шаги>
- Объём: было ~<N> строк -> стало ~<M> строк
```

## Правила
- Сохраняй полноту критичного: лучше сжать формулировку, чем потерять смысл
- Архитектурные решения (decisionsLog) не выбрасывай — только сжимай
- Не переписывай проект заново; консолидация = очистка + сжатие, не редизайн
- После консолидации Memory Bank должен оставаться самодостаточным для Resume

# Задача 03: тесты, которые действительно ловят регресс

`src/Slug.ps1` содержит `ConvertTo-Slug`. В `test.ps1` есть только один случай.

Требования:
- дописать в `test.ps1` три проверки, каждая — ровно с таким входом и ожиданием:
  - `'Привет Мир'` → `'привет-мир'` (кириллица сохраняется);
  - `'a   b'` → `'a-b'` (несколько пробелов схлопываются в один дефис);
  - `'a!b?'` → `'ab'` (спецсимволы удаляются);
- существующий тест не удалять и не ослаблять;
- `src/Slug.ps1` менять нельзя: проверяется именно качество тестов, а не кода.

Критерий приёмки: `.\test.ps1` выводит `TESTS PASS`, и при любой из трёх
намеренных поломок в `src/Slug.ps1` (проверяет `verify.ps1`) тесты обязаны падать.

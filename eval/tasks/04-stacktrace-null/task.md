# Задача 04: починить падение по стектрейсу

Пришёл стектрейс с продакшена:

```
You cannot call a method on a null-valued expression.
At C:\app\src\Report.ps1:12 char:14
+     $lines = $Text.Split("`n")
+              ~~~~~~~~~~~~~~~~
```

`src/Report.ps1` содержит `Get-ReportSummary`. Пустой или отсутствующий текст
(параметр `$Text` равен `$null`) валит функцию.

Требования:
- `Get-ReportSummary` не должна падать на `$null` и пустой строке: в этом случае
  возвращается сводка с нулями (`lines = 0`, `words = 0`);
- для непустого текста поведение не меняется;
- `test.ps1` — контракт задачи, править нельзя.

Критерий приёмки: `.\test.ps1` выводит `TESTS PASS` и завершается с кодом 0.

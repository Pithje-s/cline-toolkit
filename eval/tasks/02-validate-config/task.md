# Задача 02: валидация конфига вместо молчаливого null

`src/Config.ps1` содержит `Read-Config`. Сейчас функция возвращает `$null` в любой
непонятной ситуации: файла нет, JSON битый. Из-за этого вызывающий код падает позже
и в неудобном месте.

Требования:
- отсутствующий файл → исключение с текстом, содержащим слово `найден`;
- битый JSON → исключение с текстом, содержащим `JSON`;
- исправный конфиг читается как раньше (тот же объект, никаких обёрток);
- сигнатура `Read-Config -Path` сохраняется;
- `test.ps1` — контракт задачи, править нельзя.

Критерий приёмки: `.\test.ps1` выводит `TESTS PASS` и завершается с кодом 0.

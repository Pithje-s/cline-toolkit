# Задача 01: off-by-one в пагинации

В проекте есть модуль `src/Range.ps1` с функцией `Get-PageItems` (постраничная выборка).
Пагинация работает неправильно.

Требования:
- починить `Get-PageItems` так, чтобы страницы считались с 1 (page 1 = первые `PageSize` элементов);
- сигнатура (`Get-PageItems -Items -Page -PageSize`) и поведение на пустом входе менять нельзя;
- `test.ps1` — контракт задачи, править его нельзя;
- `src/Notes.ps1` — чужой код, не трогать.

Критерий приёмки: `.\test.ps1` выводит `TESTS PASS` и завершается с кодом 0.

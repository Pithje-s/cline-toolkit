## 03. Workflow & Search

### Правило 3 попыток (обязательно)
- Если ошибку не удаётся исправить после 3 последовательных попыток — ты ОБЯЗАН остановиться.
- Немедленно перейти в режим исследования: вызвать skill `external-research`.
- Слепой перебор кода (trial-and-error без диагностики root cause) ЗАПРЕЩЁН.
- Каждая попытка = диагностика причины + минимальная правка + повторная проверка (skill `repair-loop`), а не случайные изменения.

### Внешний поиск через MCP или OpenRouter
- Если доступен MCP-сервер для веб-поиска (см. `mcp_settings.json`, напр. `tavily`), используй ЕГО инструменты для поиска документации и решений — напрямую, без суффикса `:online`.
- Если MCP-сервера нет — используй `:online`-модели через OpenRouter (например, `anthropic/claude-3.5-sonnet:online`) для получения свежих данных из сети.
- Если онлайн-данных нет вообще — не выдумывай факты: честно сообщи и сформируй готовые ссылки (GitHub Issues, StackOverflow, офиц. документация), чтобы пользователь дал контекст.
- Запрещено выдумывать API/методы без 100% уверенности — см. skill `external-research`.

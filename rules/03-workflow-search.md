## 03. Workflow & Search

### Правило 3 попыток
- Три неудачные попытки — стоп и переход в исследование (skill `external-research`).
- Каждая попытка = диагностика причины + минимальная правка + повторная проверка (skill `repair-loop`); слепой перебор запрещён.

### Внешний поиск
- Есть MCP веб-поиска (`tavily`) — использовать его напрямую, без `:online`.
- Нет MCP — `:online`-модель через OpenRouter.
- Ничего не нашёл — не выдумывать: честно сказать и дать ссылки на GitHub Issues / официальную документацию.
